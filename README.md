# Plotline — Plot Digitizer

A browser and Windows desktop workbench for calibrating engineering plots, manually tracing datasets, and exporting calibrated values.

## Run locally

Install the Node dependencies with `npm install`, then start the development server with `npm run dev`.

For the desktop app, run `npm run desktop`. On Windows, `npm run package:win` builds a portable executable in `release/`.

## Learning and Supabase

Learning is experimental and enabled by default. After processing and manually editing a reconstruction, confirmation compares the automatic curve layer with the edited curve layer. It records exact counts of background, added, removed and retained pixels, plus up to 1,500 examples per category. Each example contains the model's nine source/automatic neighborhood features (including normalized location) and the edited label; this is a sample, not a complete reconstruction of the correction. It also computes a bounded numeric weight update. New samples do not save or upload images; a local hash prevents repeated training on the same input. Numeric comparisons, updates and hashes can still disclose information about the input. The desktop app learns only locally. The web app queues comparisons and numeric updates in IndexedDB and, when configured, sends them to a shared Supabase model without login. It retries on reconnect or every 30 seconds while open. If the browser's storage is cleared, queued updates are lost. Turning learning off stops synchronization but keeps the queue.

The model may add or remove curve pixels; changes are limited and rejected if too extensive. It can still be wrong or unchanged; review every result. Grid/axis edits do not train the model, and long gaps or details without source evidence may not be recovered. Project Undo/Redo does not undo learning. Use **Settings → Learning** to disable learning, inspect the queue or delete local learning data. Deletion also removes any images retained by an older desktop version; older images are not automatically deleted during upgrade. It cannot remove updates already sent to Supabase.

To enable web synchronization:

1. Run `supabase/learning.sql` and then `supabase/curve-comparisons.sql` in the SQL editor of the intended Supabase project. For an existing installation, run only `supabase/curve-comparisons.sql`: it preserves the model and old updates. Until the migration is applied, new comparisons stay in the local queue and synchronization reports an error. The functions create a shared model with bounded, idempotent updates. Do not run them in a project where their table names already belong to another application.
2. Copy `.env.example` to `.env.local` and set `VITE_SUPABASE_URL` to the project URL and `VITE_SUPABASE_PUBLISHABLE_KEY` to its **publishable** key (`sb_publishable_...`). Restart Vite or rebuild after changing them. For hosted builds, set the same variables in the hosting service. Never use a secret or `service_role` key in the browser.
3. Check **Settings → Shared learning** for queue and synchronization errors. Without configuration or connectivity, updates stay queued locally.

The public key and functions are accessible to anyone who can use the web app. Bounds and idempotency do not prevent spam or malicious model poisoning; do not expose this setup publicly unless that risk is acceptable. The database receives a random update ID, nine numeric weight changes, and the sampled numeric comparison, not images or local hashes. Exact counts describe differences against the user's edit, not objective accuracy; evaluate models on separate real charts before claiming improvement. The current model does not yet retrain from the stored examples, and older updates do not have comparison details. Local project JSON downloads may still contain images. The previously packaged desktop executable must be rebuilt to use the updated sample format.

## Current capabilities

- Name the project and add, switch, rename or delete chart tabs. Each chart has its own image, calibration, datasets and reconstruction edits. Deleting a chart requires confirmation; at least one chart remains. Switching charts discards temporary brush selections and healing previews.
- The workspace toolbar provides project-wide **Undo** and **Redo** for chart creation, deletion and renaming, image changes, reconstruction edits, calibration and datasets. Dragging a point is one history step. Use Ctrl+Z and Ctrl+Shift+Z (or Ctrl+Y); text fields retain their normal editing shortcuts. History holds the latest 30 snapshots in the current browser session and is not saved in project files. Confirm or discard point-review candidates before using history or switching charts.
- Upload a raster plot and use **Process image** to draw detected lines on an opaque white background. The reconstruction is lossless PNG at the source image's pixel dimensions; detected pixel-step curves are smoothed by at most half a source pixel, preserving fragment endpoints and leaving estimated bridges unchanged. This reduces jagged steps without recovering lost detail; inspect the result against the original. Process existing images again to use the updated rendering. To rebuild an evenly spaced grid, select the plot area and mark at least two consecutive lines in each desired direction using **Guide horizontal** or **Guide vertical**. The first and last guides determine the spacing; intermediate guides must be consistent. A single guide adjusts only one line. Use **Set X axis** and **Set Y axis** to mark axes independently; otherwise the lowest horizontal and leftmost vertical lines are assumed to be axes. In regular-grid mode a manually chosen axis replaces the nearest grid line, which can make that interval uneven. Disable regular-grid rebuilding for irregular grids. Compare with the original and choose the curve or grid/axis layer before drawing or erasing; drawing and erasing show a live preview on the canvas and in the magnifier. Set the eraser width; click or drag to erase. Curve strokes default to blue, grid and axes to black; adjust thickness in Process image or Settings and colors in Settings. Confirm the result before calibration.
- Calibrate X and Y in two stages: select and confirm at least two reference positions per axis, then enter their actual values, choose the scales, and confirm to continue. Auto-detect calibration points proposes the outermost grid lines, with X1 left, X2 right, Y1 bottom and Y2 top; it does not read their values. The guided workflow selects X1, X2, Y1 and Y2 in order. Other methods include individual points and two grid intersections; review and adjust the markers before confirming their positions. Linear, logarithmic, inverse, and date/time scales are supported. Data exports use pixel coordinates until calibration is confirmed.
- Create, rename, recolor, delete, and digitize multiple datasets. Click the pencil next to a dataset name to edit it in place; press Enter or the checkmark to save, or Escape to cancel. Click its color swatch to choose a color. Default colors contrast with the white reconstruction; black and white outlines keep dataset marks visible against varied backgrounds. The Delete button appears beside each dataset; the last dataset can be cleared rather than removed. During review, individual new datasets can be deleted without affecting existing ones; deleting all candidates returns to the brush selection. In Modify curve points, click a nearby point from any dataset to select it and switch to its dataset; drag or nudge it, or press Delete to remove it. The selected point has contrasting black and white outlines on the canvas and magnifier. Edit pixel coordinates in the data table, or right-click near a point in the active dataset and choose Delete nearby point. The context menu can also save the canvas as a PNG, including dataset points and calibration markers; temporary brush, guide and healing overlays are not included.
- Ctrl-click (or Command-click on macOS) datasets to select several, then use **Merge** or **Delete** and confirm. Pressing Delete while a dataset selection button is focused also deletes the selection after confirmation; it does not replace the canvas point-delete shortcut. Deleting all datasets creates a new empty dataset. When merging, the nearest endpoints are joined, reversing segments where needed; all original points are retained, including duplicates. The selected datasets are replaced with one using the active dataset's name, color and metadata. Only datasets of the same curve type and matching speed, IGV and efficiency settings can be merged; measurements cannot. Inspect the resulting connections before exporting.
- Drag a dataset's handle to reorder the list; alternatively focus the handle and use the up/down arrows. **Export Excel** creates one worksheet per chart, containing its dataset X/Y columns in order and its source image with datasets overlaid alongside the data. Empty charts still get a sheet. Invalid, duplicate or overlong sheet names are adjusted for Excel without changing the chart names. Data uses the current sort and precision settings, and pixel coordinates if uncalibrated. The overlay is an embedded image rather than an editable Excel chart. CSV and JSON data exports apply to the current chart.
- Straighten a rotated scan before processing: enter a rotation angle to preview it on the main image, then press Enter or **Apply rotation**, or choose **Straighten ruler** and drag along a horizontal or vertical axis or grid line. **Auto align axes** estimates small rotations within approximately ±8° and previews the rotation for confirmation. It can fail on unclear grids and warns when the two detected directions are not perpendicular or cannot both be verified. Rotation cannot correct perspective distortion; inspect the result. Applying rotation rotates the source image and existing dataset points, clears the reconstruction and calibration, and requires processing and calibrating again. The rotated source is used for original comparison and Excel export.
- Follow the image processing, calibration, and digitizing steps in order; **Back** reopens the previous step. The workspace remains stationary while the side panel scrolls.
- Extract curves by brushing over one or more curves, then pressing **Auto point**. Each connected brush region should contain one curve: use **Erase selection** to separate touching regions. Multiple strokes add to the selection, and **Clear brush** removes it all. Set brush width and point spacing; bends can retain more closely spaced points. When showing a freshly processed reconstruction, extraction uses the alpha coverage of its separate curve layer, including antialiased thin strokes, curve edits and erasures, rather than the composite grid or color matching. For a reopened project without reconstruction geometry, it falls back to the composite image and its configured curve color and tolerance; process again to separate the layers. When showing the original, it detects dark marks. Disconnected fragments inside a selected region can be joined; straight connections over missing ink are estimates, not measured points. Very short marks overlapping a much longer curve can be excluded as likely branches; this is reported, and they can be painted separately. Other overlapping fragments or connections outside the selection remain separate candidates, with warnings during review. Inspect every result, then confirm to edit points or discard them to adjust the brush. Saving a project during review saves the datasets but not the temporary brush or review state. Intersections, grid lines, short or near-vertical curves may be missed. In compressor mode, speed lines can also be traced by clicking a point.
- Retrace a corrected dataset as a guide to create a separate candidate for review. The original remains unchanged; compare both against the image before discarding either. This finder follows one Y value per X and does not reliably resolve crossings or near-vertical curves.
- Hide or show the image background to compare the traced datasets with the source image; this does not change the image used for extraction.
- Confirm calibration to hide its markers and show calibrated values under the cursor; reopen calibration editing to drag labeled points. Adjust curve point marker size in Datasets, including during review; it affects the canvas and magnifier without changing point coordinates, and is saved with the project.
- Choose Original, HD, Full HD, or a custom long edge in Process image. The reconstructed lines are redrawn at the selected resolution without stretching; HD and Full HD meet both minimum dimensions and never downscale. The upscaled preview is saved in the project, while detection, calibration, point extraction, and comparison retain source-pixel coordinates. Upscaling cannot recover details absent from the source; output is limited to 16 megapixels. Older projects must be processed again to change the upscaled rendering. Draw and straight-line edits each retain the width selected when the stroke was made.
- Workflow tabs allow returning to any completed step; advancing again requires confirming the image and calibration in order. Existing datasets and calibration values remain available for review. During point review, confirm or discard the candidates before navigating.
- In curve fine-tuning, optional snap moves the endpoints of drawn strokes to nearby curve-layer ink (within 12 source pixels); it does not snap to grid or axis marks. **Heal curve gap** brushes one gap and offers straight, gentle and tangent-based connections, previewed with their estimated endpoints on the canvas and in the magnifier. It looks for facing fragment endpoints instead of joining nearby sides of curves; ambiguous choices are rejected. Endpoints are estimated near the center of each stroke; when both ends align closely with the gap, the estimates coincide as a straight line. After brushing, with the canvas focused, use **1–3** to choose an estimate and **Space** to apply it. Check both endpoints against the original before applying; use the toolbar Undo to remove incorrect repairs. These are estimates, not evidence of missing scan detail. Healing supports gaps up to 100 source pixels and may refuse ambiguous or complex selections.
- When X and Y calibration markers overlap at an intersection, click the same location again to select the other marker.
- Work in Compressor Map mode with configurable axis quantities/labels/units (flow, head, outlet pressure, pressure ratio, efficiency, speed, IGV, or custom), speed and IGV tags on speed lines, efficiency-contour values, optional Surge/Choke boundaries, and structured JSON output.
- Inspect calibrated point tables, measure distances/angles, sort output by X or Y, set significant-digit precision, and export CSV/JSON (or save/reopen an editable JSON project with embedded image data).

Project files are saved by the user as local JSON downloads; image data is not sent to a server. New project files include every chart and its original and reconstructed images, calibration, datasets, and manual guides/corrections. Single-chart version 1 projects can still be opened. After reopening, press **Process image** again to edit a reconstruction. Older projects retain their original per-line guide behavior until regular-grid rebuilding is enabled. The Python calibration module in `plot_digitizer/` remains available for backend/service integration.

## Current limitations

The experimental reconstruction primarily uses line detection and skeletonized image components; the curve learning described above is optional. It may leave text, omit curves or join the wrong fragments, especially on scans and at intersections. It attempts to reconnect compatible fragments near and across detected grid lines and suppresses short outer-edge tick marks and isolated straight or slightly skewed remnants near grid lines. A genuine short curve at the plot edge or straight curve very close to a grid line may also be removed; ambiguous crossings can remain broken or be joined incorrectly. It draws a composite image rather than automatically separating all curves into datasets. Compare and correct it before use; no accuracy guarantee is provided. OCR calibration suggestions, perspective deskew, Blob/Averaging Window extractors, Polar/Ternary/Map coordinate transforms, spline smoothing, and trajectory-aware junction tracking are not implemented yet. Grid-based calibration proposes outer tick locations but requires user-supplied values and confirmation; it does not recognize tick labels. The Python calibration module includes optional OCR proposals, but it is not currently wired into the browser app. Compressor boundary stopping uses proximity to sampled boundary points; it is not geometric intersection solving.
