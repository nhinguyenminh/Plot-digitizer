# Plotline — Plot Digitizer

A browser-based workbench for calibrating engineering plots, manually tracing datasets, and exporting calibrated values.

## Run locally

Install the Node dependencies with `npm install`, then start the development server with `npm run dev`.

## Current capabilities

- Upload a raster plot and use **Process image** to draw detected lines on an opaque white background. The reconstruction is lossless PNG at the source image's pixel dimensions; short pixel steps in detected curves are lightly smoothed, with endpoints unchanged. To rebuild an evenly spaced grid, select the plot area and mark at least two consecutive lines in each desired direction using **Guide horizontal** or **Guide vertical**. The first and last guides determine the spacing; intermediate guides must be consistent. A single guide adjusts only one line. Use **Set X axis** and **Set Y axis** to mark axes independently; otherwise the lowest horizontal and leftmost vertical lines are assumed to be axes. In regular-grid mode a manually chosen axis replaces the nearest grid line, which can make that interval uneven. Disable regular-grid rebuilding for irregular grids. Compare with the original and choose the curve or grid/axis layer before drawing or erasing; drawing and erasing show a live preview on the canvas and in the magnifier. Set the eraser width; click or drag to erase. Curve strokes default to blue, grid and axes to black; adjust thickness in Process image or Settings and colors in Settings. Confirm the result before calibration.
- Calibrate X and Y axes with two or more known tick points using linear, logarithmic, inverse, or numeric date/time coordinates. A guided four-point workflow collects two references for each axis; alternatively, click two grid intersections and provide an X and Y value for each. Grid detection can predict pixel locations from horizontal/vertical grid-line intersections; the user supplies the corresponding outer tick values and can fine-tune the resulting markers and values.
- Create, rename, recolor, delete, and digitize multiple datasets. The Delete button appears beside each dataset; the last dataset can be cleared rather than removed. During review, individual new datasets can be deleted without affecting existing ones; deleting all candidates returns to the brush selection. Use Modify curve points to select/drag/nudge traced points and press Delete to remove the selected point. Edit pixel coordinates in the data table, right-click near a point to remove it, and use the cursor magnifier for precise placement.
- Follow the image processing, calibration, and digitizing steps in order; **Back** reopens the previous step. The workspace remains stationary while the side panel scrolls.
- Extract curves by brushing over one or more curves, then pressing **Auto point**. Each connected brush region should contain one curve: use **Erase selection** to separate touching regions. Multiple strokes add to the selection, and **Clear brush** removes it all. Set brush width and point spacing; bends can retain more closely spaced points. When showing a freshly processed reconstruction, extraction uses the alpha coverage of its separate curve layer, including antialiased thin strokes, curve edits and erasures, rather than the composite grid or color matching. For a reopened project without reconstruction geometry, it falls back to the composite image and its configured curve color and tolerance; process again to separate the layers. When showing the original, it detects dark marks. Disconnected fragments inside a selected region can be joined; straight connections over missing ink are estimates, not measured points. Very short marks overlapping a much longer curve can be excluded as likely branches; this is reported, and they can be painted separately. Other overlapping fragments or connections outside the selection remain separate candidates, with warnings during review. Inspect every result, then confirm to edit points or discard them to adjust the brush. Saving a project during review saves the datasets but not the temporary brush or review state. Intersections, grid lines, short or near-vertical curves may be missed. In compressor mode, speed lines can also be traced by clicking a point.
- Retrace a corrected dataset as a guide to create a separate candidate for review. The original remains unchanged; compare both against the image before discarding either. This finder follows one Y value per X and does not reliably resolve crossings or near-vertical curves.
- Hide or show the image background to compare the traced datasets with the source image; this does not change the image used for extraction.
- Confirm calibration to hide its markers and show calibrated values under the cursor; reopen calibration editing to drag labeled points. Adjust curve point marker size in Datasets, including during review; it affects the canvas and magnifier without changing point coordinates, and is saved with the project.
- Choose Original, HD, Full HD, or a custom long edge in Process image. The reconstructed lines are redrawn at the selected resolution without stretching; HD and Full HD meet both minimum dimensions and never downscale. The upscaled preview is saved in the project, while detection, calibration, point extraction, and comparison retain source-pixel coordinates. Upscaling cannot recover details absent from the source; output is limited to 16 megapixels. Older projects must be processed again to change the upscaled rendering. Draw and straight-line edits each retain the width selected when the stroke was made.
- When X and Y calibration markers overlap at an intersection, click the same location again to select the other marker.
- Work in Compressor Map mode with configurable axis quantities/labels/units (flow, head, outlet pressure, pressure ratio, efficiency, speed, IGV, or custom), speed and IGV tags on speed lines, efficiency-contour values, optional Surge/Choke boundaries, and structured JSON output.
- Inspect calibrated point tables, measure distances/angles, sort output by X or Y, set significant-digit precision, and export CSV/JSON (or save/reopen an editable JSON project with embedded image data).

Project files are saved by the user as local JSON downloads; image data is not sent to a server. The original, reconstructed image and manual guides/corrections are included in new projects. After reopening, press **Process image** again to edit the reconstruction. Older projects retain their original per-line guide behavior until regular-grid rebuilding is enabled. The Python calibration module in `plot_digitizer/` remains available for backend/service integration.

## Current limitations

The experimental reconstruction uses line detection and skeletonized image components, not AI; it may leave text, omit curves or join the wrong fragments, especially on scans and at intersections. It attempts to reconnect compatible fragments near and across detected grid lines and suppresses isolated straight remnants near grid lines. A genuine straight curve very close to a grid line may also be removed; ambiguous crossings can remain broken or be joined incorrectly. It draws a composite image rather than automatically separating all curves into datasets. Compare and correct it before use; no accuracy guarantee is provided. User ratings and edits do not train a model. OCR calibration suggestions, perspective deskew, Blob/Averaging Window extractors, Polar/Ternary/Map coordinate transforms, spline smoothing, and trajectory-aware junction tracking are not implemented yet. Grid-based calibration proposes outer tick locations but requires user-supplied values and confirmation; it does not recognize tick labels. The Python calibration module includes optional OCR proposals, but it is not currently wired into the browser app. Compressor boundary stopping uses proximity to sampled boundary points; it is not geometric intersection solving.
